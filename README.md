### 01 / Por trás dos dados

Atuo na conexão entre Recursos Humanos e Business Intelligence, com foco em transformar informações em análises claras e úteis para a gestão.

Gosto de olhar além do número: entender o contexto, fazer boas perguntas e encontrar uma forma simples de comunicar o que os dados mostram.

**Meu ponto de partida é o RH. Minha lente são os dados. Meu foco é a decisão.**

### 03 / Como penso uma análise

**Pergunta → Contexto → Dados → Análise → Decisão**

Antes de criar um gráfico, entender qual pergunta ele precisa responder. Depois, organizar a informação para que a leitura ajude quem precisa agir.
